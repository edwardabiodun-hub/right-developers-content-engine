# Operator Guide

1. Select or create an active campaign manifest.
2. Run the provider-free orchestrator to create a reviewable content package.
3. Inspect evidence statuses, mineral review profile, CTA tier, and validation output.
4. Revise rejected or warned content before human approval.
5. Record approved output and later performance observations append-only.
6. Publishing, messaging, scheduling, and commercial follow-up remain separate human-authorized actions.
